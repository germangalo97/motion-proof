# Guion visual

El guion visual manda: define el orden de las escenas, cuánto dura cada una, qué se ve y qué dice. Sin guion
aprobado no se anima. Si el usuario no tiene uno, propón este formato completo y espera su respuesta.

## Recorrido

Todo video de lanzamiento sigue el mismo camino: captar la atención, mostrar el problema, mostrar cómo el producto
lo resuelve, el resultado, y el cierre con la marca y lo que tiene que hacer quien mira. Una escena que no sirve a
uno de esos pasos se corta.

## Plantilla (30 s = 1800 cuadros a 60 por segundo)

| # | Cuadros | Segundos | Qué se ve | Texto en pantalla | Cámara | Sonido |
|---|---|---|---|---|---|---|
| 1 Gancho | 0–180 | 0–3 | | | | |
| 2 Problema | 180–600 | 3–10 | | | | |
| 3 La solución | 600–1080 | 10–18 | | | | |
| 4 Resultado | 1080–1500 | 18–25 | | | | |
| 5 Cierre | 1500–1800 | 25–30 | | | | |

Antes de seguir, comprueba que los cuadros sumen la duración exacta y que cada texto importante tenga 90 cuadros o más.

## Ejemplo completo con una app de turnos inventada

| # | Cuadros | Qué se ve | Texto en pantalla | Cámara | Sonido |
|---|---|---|---|---|---|
| 1 | 0–180 | Un calendario lleno de huecos rojos que parpadean | «¿Otra semana sin cubrir?» | Empuje lento hacia el centro | Pulso grave, un golpe en el cuadro 120 |
| 2 | 180–600 | Mensajes que llegan de a uno pidiendo cambios de turno | «Cambios. Ausencias. Mensajes.» (una palabra cada 40 cuadros) | Paneo suave a la derecha | Notificaciones sincronizadas con cada mensaje |
| 3 | 600–1080 | Clic en «Completar»: los turnos se acomodan solos, de a uno | «Un clic.» | Acercamiento al botón y alejamiento | Clic en el cuadro 640, música que sube |
| 4 | 1080–1500 | La semana completa en verde; contador de horas ahorradas | «Semana cubierta.» | Deriva lenta | Acorde que se sostiene |
| 5 | 1500–1800 | Logo y botón | Nombre de la app y «Pruébala gratis» | Empuje parejo hasta el último cuadro | Cierre musical en el cuadro 1740 |

## Números y textos

- Los números que aparecen en pantalla (precios, porcentajes, contadores) tienen que ser reales o estar marcados
  como de ejemplo. Anota de dónde sale cada uno.
- Los textos van todos al archivo de configuración, con su escena.
